# TaCZ addon

知名枪械模组TaCZ的附属模组，功能如下：

### 枪械工作台优化

- 支持按配件加成属性筛选配件。

- 材料显示简要信息且点击跳转对应的JEI配方。

- 自动保存当前筛选、分类、页码与配方浏览位置并在下次打开时跳转。

- 按SHIFT批量制作，可在配置文件中调整制作次数。

- 可从枪械工作台周围的容器取料；存储网络通过附近方块暴露可访问库存时，也可作为材料来源。

- 显示当前页码和总页数。

- 制作后弹出Toast提醒，并显示实际制作数量。

### 配件管理优化

- 新增游戏规则liberateAttachment，开启后任何枪械可随意与所有适用的配件交互，而与玩家物品栏无关。

- 普通枪械改装界面可读取玩家携带的精妙背包、附近容器，以及通过附近方块通用接口暴露的存储网络库存中的适用配件，并直接安装、替换。替换下来的旧配件返回玩家物品栏，放不下时掉落。

- 改装读取周边方块统一使用 Forge 通用物品接口，并回退到原版 Container，不按存储模组或方块类型特判。沿用附近容器扫描范围与开关；关闭周边读取不影响随身背包配件来源，不递归读取嵌套背包。

- 可指定对配件按SHIFT时展示的支持枪械数量，避免遮挡屏幕与卡顿。

- 新增游戏规则showAttachmentDetail，开启后可显示配件对当前手持枪械造成的详细属性变化。

- 增强配件属性Tooltip，同时保留TaCZ原有的其他Tooltip内容。

### 其他

- 可在客户端配置文件中指定完全作为近战武器的枪械，这些枪械的开火动作将被替换为近战动作。

- 支持换弹时开火，仅在枪械仍有可立即发射的弹药时生效。

- 按住TAB并滚动鼠标滚轮，将手上的枪械切换为物品栏中其他枪械，此按键可配置。

- 可取消TaCZ切枪时的收枪后摇。

- 第三人称视角瞄准时，自动切换到第一人称瞄准，停止瞄准后恢复原视角。

- 在玩家物品栏中对弹药盒按SHIFT并右键，可批量收集可用弹药。

- 在容器界面悬停枪械、弹药、弹药盒或配件时，可高亮与其存在TaCZ使用关系的其他物品。

- 玩家携带的精妙背包可作为弹药来源，并参与HUD弹药统计与实际消耗。

- Create Storage随身背包、胸甲槽与Curios穿戴背包可作为弹药来源，并参与HUD弹药统计与实际消耗。

- Curios槽位中的兼容弹药可参与TaCZ的弹药检测与消耗。

### 兼容性

- 支持 TaCZ 1.1.8-hotfix、1.1.8-hotfix2 与 1.2.0。1.2.0 使用独立的瞄准输入与弹药统计适配，其余功能复用经过接口验证的适配；暂无其他 TaCZ 版本兼容保证。

- JEI用于枪械工作台材料配方跳转。

- 兼容精妙背包与精妙存储，支持作为附近枪械工作台材料与改装配件来源；玩家携带的精妙背包还可作为弹药和改装配件来源。

- 兼容Create Storage 1.2.7.

- 兼容Curios，可使用Curios槽位中的兼容弹药。

- 第三人称瞄准兼容Shoulder Surfing Reloaded与Leawind's Third Person。

### 源码结构与依赖约束

项目保留单一 Gradle 模块，源码按功能组织：

| 包 | 职责 |
| --- | --- |
| `bootstrap`、`event` | 模组注册、兼容插件及事件分发 |
| `config`、`rule` | 配置与游戏规则；客户端镜像在 `client.config` |
| `network`、`network.server` | 消息与编解码、通道发送、客户端接收边界及服务端处理器 |
| `gunsmith`、`refit`、`ammo`、`gun`、`recipe` | 对应功能的业务逻辑与状态 |
| `storage`、`storage.api` | 共用库存操作、来源发现及来源契约 |
| `client.*` | 按功能划分的界面、输入、相机与连接状态 |
| `compat.*` | 按外部模组划分的兼容实现；TaCZ 契约按版本声明 |
| `mixin` | 注入与访问实现，业务只使用普通 Java 访问接口 |

消息不分发业务：`NetworkRegistration` 绑定处理器；客户端初始化绑定
`ClientPacketReceiver`，公共网络类不加载客户端实现。规则定义通过启动时绑定的回调
通知 `ServerPolicySync`。事务只接收功能数据，不接收网络 Packet。

`MaterialAllocation` 负责纯材料分配，`CraftingTransaction` 统一持有提交、回滚和物品所有权。
枪械切换与背包 HUD 分别保存具名状态，退出连接时清理。可选模组仍通过原有能力检测和惰性实现加载。

本次整理允许更改 Java 类路径及公共方法，不保留旧的 `LiberateAttachment`、
`GunSmithingManager` 门面。游戏注册 ID、配置键、存档格式和网络协议 `2.12` 保持不变。

运行 `gradlew.bat check build` 验证。`DependencyArchitectureTest` 检查编译后的包依赖图，
禁止跨包循环及业务对网络、客户端、具体 Mixin 的反向引用；允许同一功能包内必要的相互引用。
兼容测试继续使用真实上游 JAR 夹具，缺失夹具不能视为完整验证通过。
